# Public provenance and scope

## Construction basis

This Public Beta was constructed under the YamRail Human/AI safe-collaboration root value
and the D0021 system-coherence Design Review framework. Its external handoff projection also
follows D0023's founder-independent handoff standard: public visibility is not treated as
self-service, and every retained UNKNOWN/HOLD is paired with a qualified closer and next
measurement/procedure in `docs/KNOWN_HOLDS.md`.

The construction response to the prior `REWORK_REQUIRED` finding is a new, bounded browser
fixture. It does not rewrite, delete, or relabel the historical private fixture, its failures,
or its HOLD ledger.

## What is shipped

- Static HTML/CSS/JavaScript
- Deterministic synthetic worker proposals
- Session-scoped state and bounded history
- Adversarial tests for lifecycle, isolation, common mode, protection coordination, and Authority separation
- Public explanations and known-HOLD register

## What is not shipped

- Private evidence records or private repository paths
- Production credentials, tokens, personal data, analytics, or telemetry
- External model/provider calls
- A mahjong strategy model or accepted-answer oracle
- Human identity verification
- Canonical YamRail Authority/HOLD mutation capability

## Epistemic labels

All fixture-produced content is explicitly typed as one of:

```text
OBSERVED / INFERENCE / HYPOTHESIS / COUNTEREXAMPLE / UNKNOWN / HOLD / AI_ADVISORY
```

Only a browser user can create the separate local records:

```text
HUMAN_JUDGMENT / HUMAN_AUTHORITY_ACTION
```

Those local records are not proof that a qualified person acted, and have
`CANONICAL_EFFECT = NONE`.

## Handoff boundary

```text
FOUNDER CAN DO IT != SYSTEM CAN REPRODUCE IT
PUBLIC REPO != SELF-SERVICE
CLOSED / OPEN / UNKNOWN / HOLD MUST REMAIN DISTINGUISHABLE
NEXT CLOSURE POINT SHOULD BE IDENTIFIABLE
```

The deterministic teaching surface and its published receipt can be closed for the stated
Public Beta scope. Real provider behavior, identity, domain correctness, private qualification,
licensing, production and GA remain separate closure routes. No founder-only explanation,
AI consensus or browser action is accepted as closure Evidence or Authority.
